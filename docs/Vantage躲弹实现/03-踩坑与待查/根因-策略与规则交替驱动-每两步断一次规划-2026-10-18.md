## 一、先说一个**测量教训**（我在这里翻过车）

`VantageTree.getTree()` **不是返回内部 `_tree` 本身，而是每次新建一个包装对象**：
```js
function getTree() {
    var t = _tree;
    return { root: t.root, leaves: t.leaves, nodeCount: t.nodeCount, stats: t.stats, cfg: t.cfg, ... };
    // ⛔ 没有 _agentRoute / _agentFirePicks 字段
}
```
⟹ **从包装对象读 `t._agentRoute` / `t._agentFirePicks` 永远得到 `undefined`/`null`** ⟹
**"树每帧重建" 与 "射击帧恒 0" 这两个结论【都是假象】**，整晚多轮探针被它误导。

**✅ 正确读法**：读包装对象**暴露的** `stats`：
```js
VantageTree.getTree().stats.agentRouteId      // = _agentRoute
VantageTree.getTree().stats.agentFireFrames   // = _agentFirePicks.length
VantageTree.getTree().stats.agentFireFirstBack
```

## 二、用正确读法量到的真数据（200 帧）

```
stats.agentRouteId 非 null  =  96 / 200 = 48.0%     ← 路线只在一半的帧有效
stats.agentFireFrames > 0   =  11 / 200 =  5.5%     ← 几乎不开火
lastDecision.picks > 0      =  96 / 200 = 48.0%     ← B 一半的帧给的是【空 picks】
```

⟹ **策略与规则在【交替驱动】**：
- **48%** 的帧：`picks` 非空 ⟹ `_agentRoute` 有效 ⟹ **策略在开**（但每帧只走 1 帧就重选 ⟹ **小位移/抖动**）
- **52%** 的帧：`picks` **空** ⟹ `_agentRoute = null` ⟹ **`commitNode`（规则版）在开**
  而 **agent 模式下规则版的完整躲弹被关掉了**（`vantage_tree.js:93` 注释：tick 提交后直接 return ⟹ `growStep` 不跑）

⟹ **两头都占不到**：策略给不出持续规划，规则版的躲弹又不跑 ⟹ **主线玩家看到"很被动、像看不见人、小位移+原地转+偶尔开枪"**。

## 三、代码根因（B 分支，`vantage_tree.js:4572-4573`）

```js
var _route = (dec.picks && dec.picks.length) ? dec.picks[0].nodeId : dec.select;
tree._agentRoute = (_route === undefined) ? null : _route;                  // ← 空 picks ⟹ 清空路线
tree._agentFirePicks = (dec.picks && dec.picks.length > 1) ? dec.picks.slice(1) : [];   // ← 同时清空射击帧
```

**⟹ B 只要有一帧返回空 `picks`，就把**上一帧已经建立好的路线与射击帧**全部清掉** ⟹ **规划每两步断一次**。

## 四、修法（3 行，语义清晰）

> **「本帧没给」≠「作废之前的」**

```js
if (phase === 'B') {
    var _route = (dec.picks && dec.picks.length) ? dec.picks[0].nodeId : dec.select;
    // ★ 修复：本帧没给目标 ⟹ 保持上一帧的路线与射击帧（不清空）
    if (_route !== undefined && _route !== null) {
        tree._agentRoute = _route;
        tree._agentFirePicks = (dec.picks.length > 1) ? dec.picks.slice(1) : [];
        ... 统计同步 ...
    } else if (!tree._agentRoute) {
        // 本来就没有路线 ⟹ 维持 null（不必做任何事）
    }
    ...
}
```
