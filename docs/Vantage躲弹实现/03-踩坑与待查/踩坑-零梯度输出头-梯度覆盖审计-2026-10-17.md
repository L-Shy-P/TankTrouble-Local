# 🔴 踩坑：「零梯度输出头」—— 输出了，但从来没被训练

> **触发来源**：主人实机观察「就算换了权重也不该一发不打，最多乱打」⟹ 追查发现**开火头根本不在损失里**。
> **主人裁定**：「记录一下这种'根本没梯度的'踩坑，然后检查其他方面是否能训练到，比如 A 的生长。」

---

## 一、这个坑长什么样（判据）

**一个输出头"存在"≠"被训练"**。判据只有一条：
> **它是否出现在 `loss` 的计算图里**（或有梯度回流的路径）。

`train_ppo_online.py:456-458` 的实际 loss：
```python
loss = pg + cfg["value_coef"] * vloss - cfg["entropy_coef"] * ent_m
#  pg    ← node_dist(out[3])   选路分布
#  vloss ← out[0]              价值头
```
**`out[1]`（开火头）不在这条式子里** ⟹ 零梯度 ⟹ 永远停在随机初始化。

## 二、⭐ 全量梯度覆盖审计（2026-10-17）

| 决策 / 输出 | 有梯度？ | 依据 |
|---|---|---|
| `out[0]` 价值头 | ✅ | `value_coef * mse(v, ret)` |
| `out[3]` **node 段**（选路） | ✅ | `pg = -(logp(a) × A)` |
| `out[3]` **CTX 段**（`78→85` 个上下文 token） | ❌ | 从不被选为动作 ⟹ 那部分 logits **没有梯度** |
| **`out[1]` 开火头** | ❌ | **不在 loss 里**（本次踩坑） |
| **`out[2]` 失败桩 `head_fail`** | ❌ | 只有 `return`，**全仓无消费者**（死代码） |
| **A 相生长（`growAt`）** | ❌ | ⛔ 桥对 A 相**直接 `return null`** ⟹ **A 一直走规则版** ⟹ 策略**完全没参与生长** |
| **射击帧（`picks[1..]`）** | ❌ | 由 `head_fire` 派生 ⟹ 同上 |
| **`mem_writer` 记忆写头** | ❌（**设计如此**） | `net_v2_fixed.py:39-42`：`no_grad + detach`，注释原文「记忆头的梯度不会回流到本帧输出」⟹ **记忆是固定随机投影，学不出来** |

### ⟹ 结论：**现在真正在被训练的只有两项** —— 「选路（node 段）」+「价值」。
其余全是死的；其中**记忆是"随机噪声"在喂输入**，⚠️ **可能主动有害**。

## 三、为什么"会打/不会打"会随机翻转（现象解释）

三份 ckpt 的 `head_fire` 参数**几乎一致**（`std 0.037 / max 0.062` = `Linear(256,1)` 默认初始化范围）⟹ **从未被训练**。
⟹ 开火与否 = **那个固定随机向量 与 主干隐状态 的点积符号**；
主干每次训练都会变 ⟹ **符号随机翻转** ⟹ 表现为"有时规律开火、有时一发不打" ✓
⟹ **换 ckpt 等于掷硬币**，`aim`/`spawn` 这类奖励**也救不了**（它们只能训练 `out[3]` 的选路分布）。

## 四、修法（分三条，按优先级）

### ① 开火头（**最高优先**，已派）
1. 服务端 **真采样** `fire ~ Bernoulli(sigmoid(out[1]))`（现在回的是阈值 `0.5` 的确定性值 ⟹ 无法算梯度），并回传 **`lp_fire`**
2. 训练器加：
   ```python
   pg_fire  = -( logp_fire(a_t) × A_t )
   ent_fire = 伯努利熵(p_fire)
   loss = pg_node + pg_fire + value_coef*vloss - entropy_coef*(ent_node + ent_fire)
   ```
3. 采集器记 **采样到的** `fire` 位 + `lp_fire`

### ② A 相生长（**要主人拍**）
桥现在对 A 相 `return null`（那是为了不让 A 相清空 `_agentRoute`，见 `vantage_tree.js:4580-4585`）。
⟹ **生长 100% 由规则决定，策略没参与**。
要做就得**给 A 一个真正的 `growAt` 动作头**（输出"从哪个节点长"，而不是"选哪条路"），
并且**解决"A 相不能清空 B 相路线"这个接口约束**（否则接上也白搭）。

### ③ `mem_writer`（**要主人拍**）
当前设计是 `no_grad`（记忆当"输入数据"而非"可学参数"）。
⟹ 若要让记忆**真的学**，必须**推翻 `no_grad`**，让 `mem_writer` 也吃 policy-gradient（`mem` 变成动作的一部分，或至少给它一条辅助损失）。
⚠️ 在那之前，**建议先 `mem=off` 跑基线**，因为随机记忆可能是负贡献。

## 五、纪律化（写进 `AGENTS.md`）

> ⭐ **新增/修改任何"输出头"时，必须在报告里给出"它的梯度从哪里来"**（`loss` 的哪一项、或哪条回流路径）。
> ⭐ **只 `return` 不进 `loss` 的头 = 死头**，等同于"这个决策没在学"，⛔ 不许在文档里写成"已实现"。
