# 踩坑：**训练了十几轮，游戏一直跑着一个几小时前的旧权重**

> `2026-10-18` · 主人："我看起来模型行为变化极小，检查一下游戏是否应用了最新权重"
> **结论：确实没应用。上机看到的所有行为都来自 `t12`（凌晨 04:46 的 ckpt）。**

---

## 一、症状

主人反复反馈"行为变化极小""还是那么蠢"。
而我这边训练跑了一轮又一轮（`learn9/learnA/learnE/learnG/learnH/loop r1~r10`），每次都出了新 ckpt、都在留出集上评了分。

**⟹ 但游戏一次都没加载过它们。**

## 二、根因（两层，缺一不可）

### ① 默认权重文件是一个**写死的老路径**
```python
# game_core/server.py:48（改前）
VT_DEFAULT_CKPT = os.environ.get('VT_CKPT') or 'D:/vt_run/t12/ckpt/last.pt'
```
⟹ 训练产出写在新目录（`learnH/`、`loop/r10/`），**默认路径没人去改**。

### ② **服务端进程启动时把权重读进内存，改文件不会热加载**
```python
def ask(self, req, timeout=120.0):
    ckpt = req.get('ckpt') or self._ckpt or VT_DEFAULT_CKPT
    if self._proc is None or self._ckpt != ckpt or self._proc.poll() is not None:
        self.start(ckpt)      # 只有 ckpt 参数变了才重启
```
- `self._ckpt` 一旦被设过就**粘住**；
- `VT_DEFAULT_CKPT` 是**模块级常量**，改它必须**重启 `game_core/server.py`（游戏本体）**，**光刷新页面没用**。

## 三、怎么核对（唯一可靠的办法）

**打开面板的「检查点」栏**，它显示的是**运行中进程真实加载的**：
```
ckptPath / ckptMd5 / ckptStep / ckptLine("CKPT_LOADED <path> md5=<8> step=<n>")
```
**把 `ckptMd5` 和磁盘文件 md5 对一下**：

| ckpt | 文件 md5 | step | 时间 |
|---|---|---|---|
| `t12`（旧）| `43f76d2f` | 33 | 04:46 |
| `loop/r10`（新）| `df9db1f8` | 43 | 19:10 |

**md5 对上才说明真换了；对不上就是没换。**

## 四、纪律（写死，别再犯）

1. ⭐ **每次训练产出新 ckpt ⟹ 必须更新 `VT_DEFAULT_CKPT` 并重启游戏本体**
2. ⭐ **上机前先看面板 md5**，和 `md5sum <ckpt>` 对一致再下"行为如何"的结论
3. ⭐ **评测结果里已经落了 `ckpt` 和 `ckpt_md5`** —— 训练/评测/上机三方必须用**同一个 md5**
4. ⭐ **不要让 `self._ckpt` 粘住**：想换权重时，要么重启游戏本体，要么显式在请求里带 `ckpt`

## 五、这次是怎么被发现的（教训）

主人在**行为层面**感觉"变化极小"——**这是对的**。
而我这边看到的全是**离线的胜利/指标**，一直没有回答一个问题：
> **"我现在跑的这个游戏进程，加载的到底是哪份权重？"**

⭐ **以后凡是"上机表现"类结论，第一句话必须写清 `ckptMd5`。**

## 六、顺带记一笔：我自己也绕了一圈

- 一度把默认改成 `learn9`，结果 `learn9` 是**单网训**的（`model_a=None`，A 网权重丢了）⟹ 回退到 `t12`
- 回退之后再训练出 `learnE/learnG/learnH/loop`，**就忘了再改回去**
- ⭐ **教训：权重路径是"会过期的配置"，不是"设一次就完"**
