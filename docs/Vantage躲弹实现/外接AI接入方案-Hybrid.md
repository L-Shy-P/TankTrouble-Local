# 外接 AI 接入方案：Hybrid（把别人的最强 AI 搬进我们的游戏）

> 目的（主人 2026-09-07 明确）：**给我们的游戏增加挑战性**。把 AI 训练到别人的引擎里毫无意义，
> 所以路线定为**把对手搬进我们游戏**，而不是把我们的 AI 接进他们的引擎。
> 规矩：参考工程只读；要改先拷贝一份（副本在 `game_core/external_ai/hybrid/`）。

---

## 一、Hybrid 是什么（已核实）

| | 内容 |
| --- | --- |
| 模型 | PyTorch 训练 → 导出 f32：清单 `hybrid.json`（schema 24 / 观测 1028 / 动作 18 / 228280 floats）+ 权重 `hybrid.bin`（913KB） |
| 推理 | `viewer/src/hybrid.js`，**157 行纯 JS、零依赖** |
| 结构 | 地图卷积（12×10×7 → Conv16 → Conv32 stride2 → FC128 tanh）+ 子弹编码（10 槽 → 32+32）+ 标量（88 → 128）+ 主干（320 → 256 tanh）→ 18 logits |
| 混合部分 | logits 里叠加：`dodge_scale × dodge[移动码]`、开火偏置（弹药 / 命中质量 / 自杀风险）、闲置惩罚。**dodge 先验不是 NN 算的，是他们引擎 `score::dodge_safety` 给的** |
| 动作 | 18 = 9 种移动 ×（不开火 / 开火）；`action = argmax(logits)` |
| 观测下标硬约束 | 863=弹药、890=自身命中质量、891=自杀风险、893=抵达时间、1027=闲置帧数 |

**已验证**：`game_core/rust/diff_external_hybrid.js` —— 副本在**本仓库**里加载并复现对拍样本：
`action=14`、最大 logits 误差 `9.5e-7`、**单次前向 1.05ms**（我们一帧预算 20ms，够用）。

## 四、三个必须接受的损失（主人已经预见到）

1. **地图尺寸**：他们观测固定 **12×10 格**，我们迷宫格子更大（10m）。要么把对局地图限制到 ≤12×10 格（观测无损，推荐第一轮），要么裁剪/合并（行为变差）。
2. **物理手感**：他们 25Hz、格子制速度/转速；我们 50Hz、4m/s、差分转向。观测里的"速度/转速/抵达时间"是按他们的量纲归一化的 → 我们的数填进去会偏大/偏小。**先按量纲对齐填（我们有真实速度，能换算），再靠录像看它行为是否合理。**
3. **道具**：它训练环境里没有"不会用道具"这回事 → 第一轮**关掉道具**（主人已同意）。

## 五、分阶段计划（每阶段都能单独验收）

| 阶段 | 做什么 | 验收方式 |
| --- | --- | --- |
| **P0（已完成）** | 拷贝副本 + 回归套件：模型能在本仓库加载并逐位复现 | `diff_external_hybrid.js` PASS（action=14、误差 9.5e-7、1.05ms/次） |
| **P1** | 观测骨架：地图 7 通道 + 自/敌 12+12 + 子弹槽 10×10 + 阶段/动作历史/闲置；`dodge` 传 0、瞄准/威胁块先填 0 | 把我们一局的状态喂进去，观测不 NaN、不越界；在游戏里接成对手能**动起来、不撞墙发呆** |
| **P2** | 补齐导航（我们的 BFS/死路/墙射线）+ 反弹弹道 + 子弹"会不会打到我"+ `incoming_risk` + 瞄准辅助 | 逐块单测：构造已知局面，断言该块取值合理（对着我们自己的录制看） |
| **P3** | dodge 先验：先用我们的**遮蔽分**按 9 个移动码归一化近似；效果不够再移植他们的 `dodge_safety` | 对比"传 0 / 用近似"两种行为差异（录制对照） |
| **P4** | 接成可选对手（面板里多一个"外接 Hybrid"）+ 无头对局 N 局基准（我方树 AI vs Hybrid） | 胜率/存活时间基准，作为方向 3 的起跑线 |

## 六、待主人拍板的两个点

1. **地图尺寸**：第一轮用 **≤12×10 格的小地图**打（观测无损、最公平），还是继续用现在的大迷宫（要裁剪/合并，它会"看不全"）？
2. **dodge 先验**：先用**我们的遮蔽分近似**（便宜、可控、和我们自己的评分体系一致），还是要**原样移植他们的 `dodge_safety`**（最忠实、但要 600 行、还要他们的密度场）？
