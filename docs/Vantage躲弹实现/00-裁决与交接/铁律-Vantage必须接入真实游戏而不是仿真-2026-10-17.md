| | **真游戏的 Vantage** | **我造的仿真槽位** |

| 怎么来的 | `Add Vantage` 按钮 → `game_core/js/local_patch.js:859 addLobbyVantagePlayer()` → `createLobbyVantageId()` → **`Users.addLobbyAIUser(aiId, true)`**（`:1011`） | `_tools/headless/match.js:136` 直接 `vid='vantage_'+n` → `AIs.addAIManager(ttGame, vid)` + `ttGame.addPlayer(vid)` |

## 二、⭐ 两个硬判据（以后拿这个自查，别靠感觉）

1. **皮肤判据**：**真路径加出来的 `Vantage` 是 `Laika` 皮**；**游客皮 ⟹ 你还在走仿真假路径**。
2. **面板判据**：**按 `T` 能进 Vantage 面板、选"智能体模式 → 神经网络"、能调作弊/学习开关** ⟹ 这才算接进真游戏；
   **只能命令行起脚本 ⟹ 没接进去**。

## 四、⭐ 顺带记下：仿真捷径会**掩盖**真问题（本次挖出的四个实例）

| # | 被掩盖的真问题 | 怎么暴露的 |

## 五、🔴 规矩（已写进 `AGENTS.md`）

1. ⭐ **交付物必须能在【真游戏】里被主人按出来**（`T` 键面板 → 智能体模式 → 神经网络），
   **不能只有"我这边命令行能跑"**。
2. ⭐ **仿真可以简化**（少皮肤、少 UI、少 lobby），**但必须明确标注"这是仿真"**，
   并且**必须有一条"接入真游戏"的路径**被真跑验证过（**皮肤/面板判据**）。
3. ⭐ **每换一次环境（仿真 ↔ 真游戏），之前的行为/胜率数据全部标记为"待重测"**，⛔ 不许跨环境混用。
4. ⭐ **报告任何"AI 行为"数字前，先贴一条"决策真的被执行"的证据**
   （如 `buildOK>0`、`skipped:""`、`picks[0]` 被接受），**否则那些数字可能全是规则版的**。
