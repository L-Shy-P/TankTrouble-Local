## 三、A 网的尺寸 —— 从**文档已有档位表**里选，不自己发明

出处：`01-设计理论/权威与定案/智能体架构定案-2026-10-06.md:115-121`（实测计算过的档位）

| 档位 | 参数 | 占 B（2,562,849）|
|---|---|---|

| **`d=128, L=4`** | **869,281** | **33.9%** ← **采用** |
| `d=192, L=4` | 1,908,193 | 74.5% |
| `d=256, L=3` | 2,562,849 | 100%（= B）|

**采用 `d=128, L=4`（869,281 参）**。理由：
- 归属【从文档档位表选，不是新发明】
- A 的任务 = **在 N 个 node token 里选 1 个**（B 是选 1 个 **+ 逐帧射击**）⟹ 容量需求明显更低
- 保留 34% 的容量，不至于小到学不动（`d=64` 只有 186K，不到 Hybrid 的 0.8×，风险偏高）

⚠️ **待实测**：A 网的真实参数量要在建好后打印核对（`d=128 L=4` + `SEG` 各段投影 + `head_grow`），
文档的 `869,281` 是**旧输入结构**（`N×16 + 1×48`）下的口径，**现网段不同，会不一致** —— 以实测为准。
