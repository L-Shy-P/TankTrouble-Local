# 三、⭐ A/B 踩坑清单（**今晚真实踩过的，共 13 条**）

| # | 现象 | 根因 | 正确做法 |
|---|---|---|---|
| **1** | 报告写"A 相已实现"，实际 A **一次都没工作** | 桥对 A 相 `return null` ⟹ 100% 回落规则版；**静默兜底，不报错** | ⛔ **任一行`return null`/跳过/回落规则 ⟹ 必须写"该相未实现"**；交付必须给 **A/B 两相各自的"决策被接受次数"** |
| **2** | `callsA=98` 但 `growAt=0`（生长一次没落地） | `buildA()` 返回 `{picks:[{nodeId}]}` **没带 `back`** ⟹ 校验里 `targetBack = undefined`，而判断是 `!== null` ⟹ 进 back 检查 ⟹ `undefined >= 0` 为 false ⟹ **整包判"越界"丢弃**；只有 `picks:[]`（不生长）能过 | **A 的 `picks[0]` 必须带 `back`**（`{nodeId, back:0}`）。校验代码：`vantage_tree.js` `checkBundleSemantics` 的 `phase==='A'` 分支 |
| **3** | `head_grow` 有输出但**永远不变**（等于随机） | `head_grow` 不在 `loss` 里 ⟹ **零梯度** ⟹ 永远停在初始化 | **新增任何输出头，必须写清"梯度来自 loss 的哪一项"**；判据：`ent_*` 必须能从 `ln(N)` 降下来 |
| **4** | 训练出 `NaN` | ①`grow_ok` 全为 0 时 `log_softmax(-inf)` ⟹ NaN；②`-inf × 0 = NaN` | 无候选样本**用未掩码分布占位并在 loss 里排除**；用 `torch.where(valid, lp*A, 0)` 再求和 |
| **5** | 去掉 `no-op`（行 0）后 `badLp=1741 (14.5%)` | `[1,N)` 采样后 **索引没减 1**（`logp_all[idx]` 对不上） | 采样范围改成 `[1,N)` 时，索引用 `logp_all[idx-1]`；**判据 `badLp=0`** |
| **6** | 服务端报"无合法动作" | `N<2` 时 `[1,N)` 是**空集** | 显式跳过并计数（`skipNoAction`），不调服务端 |

| **8** | 树冲到 `1000` 节点上限后 A 还在被调用 | 没实现 `D11`「不能生长时不调 A」 | 用**真正的上限**判 `grow_ok_count==0` ⟹ 不调 A |
| **9** | `shots/局` 从 `4.88` 掉到 `0.5` | ⭐ **桥侧真实拼包只剩 1 条 `back`**（`mean=1`，`buckets={one:1404}`）——冗余兜底（`rel/±1/0`）被"服务端返回的 `fire_frames`"**覆盖**了，而不是**合并** | 服务端返回的与桥候选**合并去重**，⛔ 不许覆盖；**计数必须加在"真正发出去的那一层"** |
| **10** | 怀疑 `pulseBlocked` 是元凶，改完没变化 | 实测 `VT_PULSE_BLOCK=1`→`0.38`，`=0`→`0.50` ⟹ **不是元凶** | ⛔ **别拿"记录层的数"当"行为层的证据"**（当晚这类误判出现 3 次）|
