# NN 树决策讨论精华 · 2026-08-16

## 2026-08-23 最终口径更新

- 第 9 条“新弹局部失效”方向不变：只作废被新弹真正判死的节点。
- 历史现状栏里“换路线 = 下次 commit 整根重来；不能从储备库选旧节点续算”
  是当时实现缺陷，不是目标架构。**换路线只换执行路径，已模拟节点全部保留复用。**
- 树的核心不变量是 `subtreeBest = segmentScore + max(baseExt, 后代最优)`；
  满足该不变量后，从根逐层取最大孩子 = 全局最优路径。

> 本文记录 Vantage 躲弹研究中，围绕 killfield 场、神经网络决策、树循环执行模型的一次完整讨论结论。
> 作用：沉淀“为什么 killfield 行云流水”“NN 该怎么接管树决策”“执行节点如何建立与插入”等已对齐的口径。

## 一、结论速览

1. killfield 的行云流水不是搜索更聪明，而是它在一个**全局价值场**上做局部搜索；Vantage 目前是在**局部平坦的安全评分**上搜索。
2. 树的上限确实高于 killfield 的单步 MPC，但前提是树配一个能“看得远”的评分/价值来源。
3. NN 接管后，不区分价值网络与策略网络：**一个网络输出候选分数，选择 = argmax 分数**。分数就是 NN 对未来的理解。
4. NN 分数用“段内真实结果 + 下一节点 NN 估值”逐段训练，不等回合结束。
5. 时间奖励必须和**同一决策点的最优候选**比较，不能和上一轮路线直接比较，否则子弹自然逼近会被误罚。
6. 真死只有一种：某节点所有候选操作都 1 帧内死亡。普通路径死亡只是预测信息，不是真死。
7. 回退不单独奖惩；真死惩罚通过延迟结算/学习回传记到“把路线带到这里”的早期决策。
8. 执行模型：NN 每次选一个操作 + 一个时长；正常到时长末尾建新节点；任何一帧出现极端情况就**中途插入新节点**，旧时长剩余部分作废。系统是“能每帧换”，不是“每帧必换”。
9. 新子弹进入时，只增量重建被该子弹判死的节点及其整棵子树；不整树重建。中途插节点是独立的每帧极端情况检查，不和新弹增量失效混在一起。

## 二、killfield 场的本质（为什么它像有地形理解）

killfield 的场分三步：

1. **反向射线**：从敌方格向外射 2048 条射线，按墙反射，最多 2 次反弹、3 秒飞行。射线扫过的格子，就是从这些格子能打中敌人的射击位票数。
2. **分层价值**：票数按 log 归一到 7 层，价值取 2 的层数减一次方。每高一层翻倍，保证高一档价值压过下一档噪声。
3. **距离传播**：对每个正票数格子，以 `源质量 × exp(-0.18 × 迷宫最短路距离)` 向所有可达格传播，逐格取最大并归一化，得到全图连续、单调的引导势能场。

在线评分消费的是势能场的**累计爬升、峰值、引导爬升、净位移**。所以 killfield 的局部搜索等于“沿坡走”，组合解是重规划逐段粘出来的，不是单次 rollout 直接看到的。

结论：

- killfield 的场 = 手写的全局长期价值函数；
- Vantage 树 = 更强的搜索器；
- 未来 NN 价值 = 学出来的动态长期价值函数。

## 三、束追踪、波场与“解析法”的判断

1. 子弹聚集成的“波”是经典粒子的强度场，不是量子波。应使用输运方程（几何光学/辐射传输），不能使用波动方程，否则会出现现实不存在的干涉、衍射。
2. 对任意迷宫 + 有限反弹，一般没有初等闭式解析解。
3. 更高精度 + 更高性能的直接几何法候选是**束追踪**：追踪角度区间而不是单条射线，得到连续多边形覆盖，可支持格内精度。
4. 束追踪实现难度高（墙角、掠射、同距离多墙），当前不是主线。可以先降采样 killfield 射线场（256~512 条）作为基线和特征。
5. 输运网格离散迭代（离散纵标法）在低方向分辨率时快，但角精度不如射线；K 的高方向分辨率场景下未必更快。

## 四、NN 决策架构口径

### 4.1 一个网络，一个分数输出

- 不强制分价值头/策略头。
- NN 给每个候选节点输出一个分数。
- 树选择 = argmax 分数。
- 如果未来需要探索/不确定性分配预算，再考虑额外输出，当前不引入。

### 4.2 分数的训练目标（逐段自举）

每执行一段：

```
节点A被选中，执行 L 帧到达节点B
训练目标(A) = L帧内真实结果 + NN(B)
```

- 这是稠密信号，每个节点执行完都能学一次，不等回合结束。
- B 之后真死，B 的分数下降，A 的分数沿训练回传下降，选路自然避死。
- 最终回合胜负/长期存活仍可做低频校正，但不是唯一老师。

### 4.3 节点分数的存储语义

- NN 输出的分数是权威。
- 节点上可以存分数，但只作**缓存、渲染、调试、掉线兜底**。
- 缓存与 NN 重新输出不一致时，以 NN 新输出为准，缓存只更新，不反向纠偏。
- 传统树“从叶子向根回传数值”在当前 NN argmax 选路架构里不是必需；需要回传的是**学习信号**（谁为后面的真死负责），不是节点显示分。

## 五、死亡、回退、坍缩的奖惩口径

### 5.1 死亡

- **路径死亡**：某条 75 帧预测里有死亡，正常，不惩罚。
- **真死**：某节点 9 种候选全部 1 帧内死亡，即当前状态无解。真死才重罚。
- 真死惩罚记在新节点上，并把责任沿“谁把我带到这里”的决策链回传；前面已执行帧的生存分不取消。

### 5.2 回退

- 回退本身不额外奖惩。
- 回退后很快再次真死，自然通过第二次真死惩罚体现“回退位置选得不够早”。
- AI 通过反复失败学会该提前多少个节点、该在哪里换路线。

### 5.3 时间补偿

- 路线时长和**同一决策点所有候选中的最长时长**比较：
  - 选到最长路线：0 或小正分；
  - 选到明显短路线：扣分。
- 不和上一轮路线直接比较，避免子弹自然逼近、新弹出现导致所有路线时长一起缩短时误罚 NN。

### 5.4 坍缩与报废

- **正常提交坍缩**：选中一条路线后其他兄弟被弃，是成功，不扣分。
- **报废路线**：已经提交/计划执行、但未执行完就作废的路线。
  - 因新弹等外部变化报废：不罚，只结算已实际执行部分；
  - 因自身选择问题报废：扣未执行尾巴的分。
- 惩罚项总数保持少：真死 + 报废 + 时间补偿，不再加零散惩罚，防止权重过多导致乱学。

## 六、树循环执行模型（本次讨论定稿）

```
每个决策点：
  1. NN 从候选节点中选一个操作
  2. NN 同时选该操作的执行时长 L（1~上限）
  3. 提交执行，段内操作恒定

正常路径：
  执行满 L 帧且现实对齐通过
  → 在当前位置建立新节点
  → 展开候选、NN 重新选择下一操作与时长

极端情况（每帧独立检查）：
  任意一帧出现：
    实际位姿与预测偏差超容差
    当前执行路线的预测在段末前死亡
    NN 主动给出换操作信号
  → 在当前帧插入新节点
  → 旧时长的剩余部分作废
  → 立即重新选择操作与时长
```

- 目标不是“每帧必换”，而是“每帧都能换”，在需要时具备应激能力。
- 长段用于稳定走位，短段用于危险反应；时长由 NN 根据预测决定。

## 七、新子弹的增量失效（替代整树重建）

新子弹进入后：

1. 对新弹算反射折线。
2. 遍历树中存活节点，用新弹与该节点 rollout 样本逐帧做死亡检测。
3. 找到第一个被新弹判死的节点，删除该节点及其整棵子树。
4. 受影响父节点的空缺子节点，用含新弹的威胁集合重新展开。
5. 未受影响的节点和子树原样保留。
6. 只有根节点在当前时刻已与新弹相交（立即真死）等极端情况，才允许整树重建。

这与 00-总体规划中“新子弹只淘汰被它杀死的旧节点，不整树重建”的既定原型边界一致。

## 八、尚未闭合的接口清单

1. NN 分数如何进入当前 `segmentScore / subtreeBest` 的提交比较（现在是普通评分口径）。
2. 中途插入新节点的统一触发接口（当前只有新弹重建 + 段末对齐检查）。
3. 新弹增量失效的节点遍历与重展开实现。
4. NN 训练样本收集器：每个已执行节点的（前状态、选择、时长、真实结果、下一节点）。
5. 时间补偿基准的候选集口径（根层 9 候选，还是全部已展开候选）。

## 八点五、当前树框架 vs NN 框架差距清单（2026-08-16 检查）

当前树已具备：

- 节点状态：输入操作、位姿、相对弹道时间、段长、段分、子树分、rollout 样本；
- 每层 9 选 1、argmax 金线、预览链生长；
- 段末新鲜重选、新弹立即重选、对齐失败重选；
- 执行轨迹 execTrail、被弃兄弟 doomedSnaps、事件日志。

当前树尚缺（NN 接入前必须补齐）：

1. NN 选节点/选操作/选时长的调用点：现在全是 `pickBest + probeSegment` 手写规则。
2. NN 分数进入 `segmentScore / subtreeBest` 的接口。
3. **回退机制**：v11 已有“某节点 9 候选全死 → 标记 exhausted → 回父节点换存活兄弟”的基础版；仍无 `onRetreat/onStableCommit` 协议、无储备库 reservePool、无“多数死亡/存活均分过低”判定、无回退后段长衰减。
4. 换路线机制：现在换路线 = 下次 commit 整根重来；不能从储备库选旧节点续算。【2026-08-23 作废：这是历史缺陷，不是设计。换路线必须保留并复用旧节点。】
5. 新弹增量失效：仍是整根新鲜重选，不是“只删被新弹判死的节点及子树”。
6. 训练样本收集器：执行轨迹只有渲染快照，没有（前状态、选择、时长、真实结果、下一节点）训练记录。

结论：当前树是**单节点模拟的段制 MPC 外壳 + 未来预览**，还不是完整 NN 树框架；下一步优先做 3、5、6。
