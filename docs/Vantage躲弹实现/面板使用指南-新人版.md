# Vantage 面板使用指南（新人版）

这份指南面向刚接触 Vantage、还不了解内部预测树的人。
你不需要懂代码，只要会用面板上的按钮和滑块即可。

---

## 一、先记住 5 个按键

| 按键 | 作用 |
|---|---|
| `T` | 打开 / 关闭调试面板 |
| `P` | 暂停 / 继续游戏 |
| `Y` | 打开 / 关闭树图 |
| `/` | 寻路到当前能走到的最远格子 |
| `V` | 打开 / 关闭子弹与遮挡标注 |
| `E` | 导出当前诊断数据 |

面板打开后，所有操作都可以用鼠标完成，不一定需要记快捷键。

---

## 二、面板从上到下分成 4 块

1. **按钮行**：暂停、单帧、标注、树图、导出。
2. **AI 操控**：选择 AI 当前怎么打。
3. **实验参数**：按类别分成“评分 / Rust / 生长 / 回退 / 选路”几行。
4. **数据区**：实时数字和折叠详情。

把鼠标停在任意实验项上大约半秒，会弹出一句功能说明；不需要记每个名字的含义。
当前设置下不会生效的滑块和对应开关会一起变灰，但仍然可以拖动或点击开启，方便你提前调好数值。
面板默认出现在地图左侧，打开面板时会默认同时显示树图；面板和树图都可以拖出屏幕。
点击游戏地面时：
- 场上有子弹：不会直接接管 AI 驾驶，只给树一个“目标位置偏好”，并且只在几个操作安全分完全相同时，才比较末状态位置和朝向。
- 场上没有子弹：走迷宫最短路寻路，会真正绕过墙向目标移动。
- 场上没有子弹、也没有点击目标时：AI 优先静止，树只做预热生长，不会自己乱选前进或转向。

---

## 三、AI 操控怎么选

- **自动（每轮最高分）**：不做树搜索，每轮 9 个操作里选分数最高的。适合快速对比。
- **树（预测树循环）**：Vantage 的主力模式。AI 会向前预测、长树、在树里选路线。
- **具体操作**：下拉里可以直接指定“前进 / 后退 / 左转 / 右转”等单个操作，常用于排查问题。

只有切到 **树** 模式，面板里才会出现“生长 / 回退 / 选路”这些参数。
没切到树时它们会自动隐藏，避免看不懂的开关堆在一起。

---

## 四、实验参数分类说明

### 1. 评分（所有模式通用）

- **固定帧数评估**：打开后，无论真实帧率高低，都按固定帧数评估候选操作。
- **仅操作时长评分**：只累计每个操作自身时长内的帧分，不再固定看 75 帧；更容易发现“先转向再前进”这类组合技，但远期信息会变少。
- **帧数滑块**：配合固定帧数评估使用，范围 1~300。
- **轨迹距离评分**：评估坦克路线与子弹轨迹的距离，靠得太近会额外扣分。
- **弹簧绳评分**：对贴墙或太窄的路线额外扣分，鼓励更舒展的走位。
  - Rust 物理模式下 Rust 路径不支持它，所以开启 Rust 物理时这一项会自动隐藏并关闭。
- **死亡不扣分**：实验用，死亡帧不再立刻扣分，只停止后续计分。正常玩不要开。

### 2. Rust（执行引擎）

- **Rust 物理预测**：默认开启，用 Rust/WASM 做更快的物理预测。
  - 桥没加载好、遇到 Rust 不支持的配置时，会自动回退 JS 融合世界，不会影响正常游玩。
  - 想看纯 JS 行为时可以手动关掉它做对比。

### 3. 生长 / 节点（只有树模式显示）

- **无子弹时预热**：没有子弹时也让树继续长。适合开局前提前预热，但会占内存和计算量。
- **每帧生长层数**：每个游戏帧最多新增多少层树节点。默认 1，通常最稳。
- **节点数量上限**：预测树最多保留多少个节点，默认 500；旁边的“启用”决定是否生效。
- **预热上限**：没有子弹时的独立上限，默认 500。
  - 即使关掉“节点数量上限”，预处理也不会无限生长。
  - 子弹一出现，这个上限就自动解除。
  - 开局等很久再发子弹时，它是防止卡顿的关键。
- **预测时长上限**：树的预测时间长度，范围 1~15 秒，默认 8 秒；旁边的“启用”决定是否生效。
- **超上限细化长路径**：到达节点或时长上限后，继续把长操作从中间拆开找路。
- **细化长路径**：不等到达上限，每个游戏帧都额外拆一次长操作。
  - 更强，但计算量和节点增长都会明显上升，默认关闭。
- **剪枝补偿层数**：新子弹导致大量节点被剪掉后，接下来几帧每帧额外多长多少层节点；范围 0~9，默认 0。
- **补偿持续帧数**：剪枝补偿持续多少帧；范围 1~60，默认 1。

### 4. 回退（只有树模式显示）

当一条路线被预测为必死时，AI 会往后退，换一条活路。

- **回退节点数**：最多向上退多少节点，范围 1~32，默认 3。
- **回退帧数**：最多向上退多少帧，范围 10~600，默认 200。
- 两个上限谁先到，就从哪里开始找替代路线。
- 如果那一层没有活路，AI 仍会继续向更上层找，不会完全不回退。

### 5. 选路（只有树模式显示）

- **Rust 简化选路**：实验功能，只让 Rust 参与最终选路，不参与物理模拟和树结构；默认关闭。
- **混合选路**：开启后目标位置分直接加进安全总分，AI 可能为了靠近目标选择安全分稍低的操作；关闭时仍是两阶段：先选安全的，再在同分路线里选更接近目标的。
  - 场上没有子弹时不需要这项，AI 会直接走迷宫最短路寻路。
- **目标分系数**：0~300%，只在混合选路开启时生效。
  - 0%：不看目标；
  - 30%：轻微引导；
  - 100%：目标与安全大致同权；
  - 200%~300%：强目标引导，可能明显牺牲安全。
  - 二阶段选路下改这个值不会影响结果。
- **自动寻路**：开启后，如果 AI 当前没有用户指定目标，会自动寻找最近的边界/封闭房子并过去，方便压力测试；有用户点击目标时不会自动寻路。
- **全局选路**：实验功能，当前版本开启后 AI 会明显变弱，暂不建议开启；默认关闭。
- **重置配置**：将配置重置为作者 L_Shy_P 实测出的 AI 较强且性能不错的配置。
  - 会把“细化长路径”关掉、“回退节点数”设为 3、“回退帧数”设为 200、“预热上限”设为 500、“预测时长”设为 8 秒、“剪枝补偿”设为 0 层/1 帧。

## 五、树图怎么用

- 默认贴在**地图右侧边缘**，不遮地图；如果拿不到地图，才贴游戏画布右侧。
- 按住树图标题栏可以拖动；树图和主面板都不会被限制在屏幕内，可以拖出视口。
- **双击标题栏**可以恢复到默认位置。
- 鼠标滚轮：以光标位置为锚点缩放。
- 在画布上按住拖动：平移。
- 点击节点：下面显示该节点的段长、分数、死亡帧等信息。

---

## 六、数据区怎么看

- **FPS**：当前游戏帧率。
- **轻算 / 9op**：单帧评分和 9 操作评估的耗时。数值越小越流畅。
- **执行**：AI 当前正在执行的操作。
- **树 节点 / 预热≤**：当前活动节点数；旁边是节点数量上限或预热上限。
- **折叠区**：基准详情、评分详情、树详情、沙盒 9 操作、威胁、分数曲线。
  不展开时不会影响性能；需要排查时再点开。

---

## 七、常见现象

- **没有子弹时树不长了**：先看是不是到了“预热上限”。这是正常保护。
- **换成 Rust 物理后“弹簧绳评分”不见了**：Rust 路径不支持它，属于正常行为。
- **面板里只有评分和 Rust 两类参数**：说明当前不是树模式，切到“树”后会出现生长、回退、选路。
- **AI 一直不动**：先看“执行”行和“威胁”折叠区，确认有没有子弹、树是否启动。
- **帧率突然下降**：看“9op”耗时和树节点数。节点数太高时，优先降低“节点数量上限”或“预热上限”。

---

## 八、一句话推荐

新手先保持默认：
**Rust 物理预测开、每帧生长层数 1、节点数量上限 500、预热上限 500、预测时长 8 秒、剪枝补偿 0 层/1 帧、回退节点数 3、回退帧数 200、细化长路径关。**

面板默认就是这套配置；如果不小心改乱，点“重置配置”即可恢复。
然后选“树”模式观察。熟练后再根据帧率与实战表现，优先调“节点数量上限”“预热上限”“预测时长”“剪枝补偿层数/持续帧数”“回退节点数/回退帧数”。
