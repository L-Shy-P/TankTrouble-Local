## 二、合法性规则（标签的来源）

阶段 0 要学的就是这些。**执行层最终会强制前两条，网络学它们是为了少走重试。**

| # | 规则 | 级别 |
|---|---|---|
| R1 | `fullDeathFrame <= 1`（真死）的节点**不能作为 `growAt` 的父节点** | **不变量①，执行层强制** |
| R2 | 存在非真死候选时，`select` **不能**指向真死节点 | **不变量②，执行层强制** |
| R3 | `growAt` 里的 id 必须**真实存在**于本 tick 的 ctx.nodes | 结构性非法 |
| R4 | `select` 必须**真实存在**且**合法** | 结构性非法 |
| R5 | `invalid`（结构失效）/ `exhausted`（耗尽）的节点**不能**被 `growAt` 或 `select` | 结构性非法 |
| R6 | 节点数量达到上限后**不允许再 `growAt`**（程序会拒绝，但不算错） | **不罚**（资源上限） |

> 惩罚分级（不变）：R1/R2/R3/R4 重罚 · R5 中罚 · R6 不罚。
> **一律重罚会教出"什么都不做"**——用户定案。

**不变量③**（只有 0 帧自杀射击算绝对错误）属于射击头，**阶段 0 不涉及**。

### 3.3 树结构的传递

自注意力要求节点之间能互相看，**但网络还需要知道父子关系**（生成路线要沿父子边）。

**方案**：节点 token 里带**父节点的槽位索引**（不是 id）作为额外的注意力偏置，
或者用**父子边掩码**限制生成时的候选集。

**本阶段采用**：把「合法子节点集合」作为**生成掩码**逐层传入（见 §4.3）。

## 四、网络

### 4.1 结构

```
输入：N × 16（节点） + 1 × 48（全局）
    ↓ 线性投影到 d=256
    ↓ + depth 编码 + isRoot/isLeaf 类型编码
Transformer Encoder × 3 层（d=256, 8 heads, FFN 4×）
    ↓
┌─────────────────┬──────────────────────┐
▼                 ▼                      ▼
A_grow 头        A_len 头              B_fire 头
逐节点 → 1       逐节点 → 1            全局 → 30
sigmoid          sigmoid               sigmoid
"这能长吗"       "这段多长"            射击表（本阶段不训）
```

**参数量 2,562,849**（d=256, L=3）。

**生成路线时（`select`）**：Transformer 输出的节点表示**不额外接头**，
而是逐层用**候选子节点的表示两两算相似度/打分**，softmax over 合法子节点：

```
当前节点 c 的表示 h_c
候选 = c 的合法子节点
      ↓
score_i = MLP([h_c, h_i, h_c ⊙ h_i])      ← 一个小头，参数极少
      ↓
softmax over 候选 → 选一个 → 沿边走到它 → 重复
      ↓
到叶子终止（【不需要结束符】）
      ↓
输出整条路线，接口上交 `select = 路线终点节点 id`
```

> **为什么用 `[h_c, h_i, h_c⊙h_i]` 而不是直接对 h_i 打分**：
> 候选的合法性/优劣**取决于"从哪个父节点出发"**。同一个子节点从不同父节点看价值不同。
> 拼上 `h_c` 才能表达"我在 c 这个位置，去 i 好不好"。

### 4.2 训练目标（阶段 0）

| 头 | 损失 | 标签 |
|---|---|---|
| `A_grow` | BCEWithLogits，逐节点 | 该节点**能**长 = 1 |
| `A_len` | MSE + 越界惩罚 | 该节点对应的合法段长（钳到 [3,30]） |
| `B_pick`（逐层） | 交叉熵，只在**合法候选**上 | 在合法候选里随机挑一个（阶段 0 不追求最优，只追求合法） |

**阶段 0 不追求打得好，只追求一次就合法。**

### 4.3 生成掩码

逐层生成时，候选集 = **当前节点的合法子节点**（排除 `invalid` / `exhausted` / 真死）。
如果当前节点**没有**合法子节点 → 该分支终止。

**`select` 的整体合法性**：由 R2 保证——若存在非真死候选，路线终点不能是真死节点。

## 五、数据生成（合成，不跑游戏）

```
for i in range(BATCH):
    1. 随机生成一棵树：
         节点数 1~512，深度 1~20，每节点子节点数 0~9
         随机标记 invalid / exhausted
         随机给 fullDeathFrame（含 <=1 的真死）
    2. 程序判定每个节点的合法性（§二的规则）→ 标签
    3. 编码为 token 序列（§三）
```

**纯 CPU、纯 Python 3.13，几秒生成百万样本。**
