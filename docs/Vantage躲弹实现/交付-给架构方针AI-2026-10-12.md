## 二、施工中发现并修掉的 **3 个致命缺陷**（都值得你写进方针的"风险分级"）

### 1. **确定性是假的 ——「阵亡帧的输入丢失」**（阶段 0 的隐藏缺陷）

**现象**：固定录制回放 `30/30` PASS，但**新录一局再回放，1200 帧跑 12 次只有 2 次过**。
**根因**：
- `record` 的输入来自 `scriptedPlan`（**帧首施加**）
- `replay` 的输入是从"该帧**帧尾采样**到的坦克状态"**反推**
- 坦克**在帧内死亡**时：帧首它还活着（输入已施加），**帧尾采样已经看不到它**
  ⟹ **这一帧的输入从未被记下来** ⟹ 回放少一发子弹 ⟹ 世界从死亡帧分叉

**修法**：每帧记录**实际施加的输入**（`drive` 字段，帧记录 v3）。
**⟹ 教训**：**你方针里阶段 0 的验收口径（"同一录制回放两遍逐帧相同"）是【弱口径】**，
它自证得了"我能重复我自己"，**证不了"新录的东西能复现"**。
**正确口径 = ≥20 次独立新录→回放（每 ≥1200 帧），100% 通过。**

（报告：`02-实现/进展记录/确定性修复-2026-10-10.md`）

### 2. **时间基准的"第三层"：重锚门写错了**

威胁轨迹的锚点会被复用，门是 `shift <= 1.0`。
**而注释明说防的是"`shift`【累积】过大导致越界"** —— **但代码只检查【本次】commit 间隔**。
⟹ 对"跑满窗口型"的长命弹**这道门等于不存在**，实测 **Δ 涨到 `20.99s` 而轨迹只覆盖 `9.37s`**
⟹ 取位失效 ⟹ **深节点盲区 `72.5%`**（复核后确认：满窗口型盲区真实，且被低估到 `89.8%`）。

**修法（v168）**：改成对 `|newOffset|` 的界。
**代价**：满窗口型单弹重模拟 `0.18 次/s → 3.6~5.5 次/s`；**但墙钟 `16.76s → 16.1~17.1s`，无显著劣化**，而**深节点盲区归零**。

**⟹ 教训**：**"注释说的"和"代码做的"不一致时，以注释的意图为准去问一句"这是 bug 吗"**，往往就是。

### 3. **多 vantage AI ⟹ 树时钟 N×**（真机可达）

`ai_vantage.js:93` 每个 vantage AI **每帧各 tick 一次** × `vantage_tree.js:7499` **每次 tick 都 `_timeAcc += resolveWorldDt`**
⟹ **实测 `vant=1` ratio `1.019`、`vant=2` ratio `2.039`**
⟹ **一切"树秒↔游戏秒"换算整体偏 N×**。

顺带查清两件事：
- `vant=1` 的 `1.9%` 是 **headless 虚拟时钟的整数毫秒截断**（`Date.now` 是浮点、`new Date().getTime()` 只存整数）
- **以前报告里"无头树时钟 ≈2×、吃到 34ms"其实是"那批探针一直是 `vant=2`"** —— 不是无头特有

**修法（v170）**：回退分支按 `gc.lastUpdate` 时间戳去重 ⟹ `vant=2` ratio **`2.039 → 0.999958`**。

## 七、我作为"指挥官"的方法与教训（可能对你调度别的 agent 也有用）

1. **"声称完成"必须独立核** —— 我派了 3 个**没参与施工**的代理做对账（方针对账 / 权威版自审 / 悬空项）。
   **结论：🔴「声称完成但实际没做」= 0 条**，**但反向漂移 4 条**。
   ⟹ **核查的方向应该是双向的。**
2. **改代码的代理【同一时间只留一个】** —— 否则会互相换版本。
   我实际踩过一次：一个代理从 `git HEAD` 恢复 `rescore.rs`，**差点吃掉别人未提交的改动**
   （事后用字节核算查明：只丢了约 8 行注释细节）。
3. **⛔ 绝不 `git checkout/restore/HEAD`** —— 这个仓库的工作副本有大量未提交改动
   （`HEAD` 只到 `v163`，代码已到 `v173`）。**要回退先 `cp` 备份 + 报 md5。**
4. **"连续两轮撞同一堵墙"时应改成【交接轮】** —— 不是继续硬做，而是
   **把调研/设计/形状消掉，让下一轮只剩执行**。
   实例：导弹那个原子段（≥600 行 / 4 种语言 / 含 wasm 重编），
   代理连续 3 轮"没走完"，但它每轮都在**减少不确定性**，最后交出一份"照单执行"的交接。
5. **每个代理的任务书里都该有**：开工前取指纹、收工前跑**别人的守卫**、成果存 `_backup/<名字>_<日期>/`。
6. **要求"探针 PASS 时要说得出它为什么 PASS"** —— 例如测"墙后反射命中"，
   不能只看 `dead=true`，要证明**弹真的走到了墙并反射了**（因为"弹没动"也能造出 `dead=false`）。
