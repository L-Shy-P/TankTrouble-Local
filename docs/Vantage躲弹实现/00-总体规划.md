# Vantage 躲弹原型 · 总体规划

> AI 代号：Vantage（原名 Laika_Pro，2026-08-14 已全局改名：类 VantageAI/VantageAIManager、ID 前缀 vantage_、文件 ai_vantage.js）
> 目标：静态躲弹原型——验证预测树理论是否成功
> 日期：2026-08-09

## 2026-08-23 最终口径更新（优先于下文中所有冲突描述）

1. **换路线 ≠ 删除节点。** 未选中的分支、回退后离开的分支，都是已经模拟出来的
   真实结果，必须保留并可在后续搜索中复用。任何“整根重来”“其余全弃”“换路线 =
   下次 commit 整根重来”的描述均为历史错误口径，全部作废。
2. **全局最优路线** = 每个节点的 `subtreeBest = 本段分 + max(恒定尾分, 后代最优链分)`。
   只要该不变量成立，从根逐层选 `subtreeBest` 最大孩子即等价于全局最优路径。
3. **死亡判定唯一权威 = 游戏同源碰撞。** 静态重叠式 checkDeath 是历史妥协，必须
   替换为融合世界中子弹飞行 + 传感器接触 + CCD。详见 01 与《单世界融合沙箱实施方案》。
4. **评分仍在考究中。** 当前角度遮蔽分在安全时容易整圆满分（约 39.48/帧）；
   需增加“路径距离/净空”类项，并统一车道压分开关。详见 02 的最终口径更新。

## 原型边界（主人定的规矩）

- **只做静态躲弹**：不看对手位置、不看炮管角度，纯躲已有子弹
- **新子弹增量处理**：新子弹产生时，不让已有节点死亡就不重算；只有当它让"原本存活的节点变死亡"时，才抛弃那个老节点（避免每来一颗子弹全树重建）
- 这是研究检验理论的原型，以后会有更优处理

## 改造总思路：换芯不换壳

`VantageAI.update(deltaTime)` 里现在的逻辑是"有目标就寻路，没目标就站桩"。
改成：**每帧跑一遍预测树帧循环（6大步），把选出的操作写成 InputState**。

I/O 接口一行不动，只换决策内核：

- **数据获取（已验证可用）**：`gameController.getTank/getProjectiles/getMaze/getB2DWorld`
- **操作反馈（已验证可用）**：`InputState.withState(aiId, 前,后,左,右,开火)` → `gameController.setInputState()`
- **子弹反射折线（游戏现成）**：`B2DUtils.calculateProjectilePath(b2dWorld, projectile, bounces, pathLength)` 直接返回反射路径

## 双接口预留

- **游戏AI接口（对外，可移植）**：靠"换芯不换壳"自然达成——输入=游戏数据+常量+沙箱，输出=按键。换游戏版本只要能喂数据、收按键就能跑。
- **神经网络接口（对内，可插拔）**：在延伸/回退/换路线几个决策点留钩子，现阶段走手写规则，未来可切换成"节点特征喂给NN、NN返回决策"。钩子先埋好，不实现。
