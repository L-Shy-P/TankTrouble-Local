# 记忆槽 · 数据格式设计（AI 工程决定，2026-10-15）

> **本文性质**：**工程决定**（**不是主人待拍的问题**）。
>
> **分工依据**（主人 `2026-10-15` 原话）：

> > 我最多也就设计到"它得有记忆"这个程度了**」
>
> ⟹ **主人定了【语义】**（**`双智能体架构 §13.1`**）：
> **必须有记忆 · 双份 · 双方都能看 · 自己只能改自己的 · `A` 先 `B` 后（跨帧无竞争）** ✓
> ⟹ **本文定【格式】** —— 而**格式由"网络怎么读它、怎么写它"决定** ✓

---

## 一、第一原则：**记忆是【token 段】，不是"一个向量"**

**依据**：**网络是 Transformer**（`定案-2026-10-06 §二`），**输入是【各类 token 段拼接】**（`v4 §三`：
全局 token · 对手 token · 子弹 token · 节点 token · 毒雾段 · 回忆段…）。
⟹ ⭐ **记忆必须是同一套东西 —— `K` 个 token × `d` 维**，**才能被拼进输入** ✓

---

## 二、`d` 取多少 —— **跟网络的 `d` 走**

**依据**：**`v4` 定 `d = 256`**（**`Transformer 骨架，d=256 L=3 起`**）。
⟹ ⭐ **记忆 token 的维度 = `256`**（**与其它 token 段一致、不用额外的投影层**）✓

---

## 三、`K` 取多少 —— **每份 `2` 个 token**

**依据（这是最主要的工程约束）**：**"写记忆"要占【网络输出】的预算** ⚠️
- **网络输出已是三头**：**`growAt`（选节点）· `select`（选路线）· 射击帧**
- ⚠️ **而"写记忆"是【连续值输出】** ⟹ **要加一个回归头** ⟹ **`K × 256` 个输出神经元**
- **`K = 1` ⟹ `256` 个** · **`K = 2` ⟹ `512` 个** · **`K = 4` ⟹ `1024` 个**（**这是【输出个数】**）
- ⚠️ **纠正（`2026-10-16`）**：**原稿此处写「`512` 个输出头是 `0.02%`」是【错的】** ——
  **它把"输出个数 `512`"当成了"参数量"** ⚠️。
  ⭐ **正确的账**：**这层参数量 = 输入 `d=256` × 输出 `512` = `131,072`** ⟹
  **`131,072 / 2,562,849 = 5.1%`**（**不是 `0.02%`**）✓
- **⟹ 所以 `K = 2` 的代价是【`5.1%` 参数、不是"可忽略"】** ⚠️（**仍然不大，但要说实话**）✓
- ⚠️ **但"回归头在 RL 里难训"** ⟹ **不宜太大** ⟹ **`K = 2` 是"够用 + 不太大"的折中** ✓

**⟹ 定：`K = 2`（每份记忆 = `2` 个 token × `256` 维 = `512` 个数）** ✓
⚠️ **将来可调**（**它不改变任何架构，只改一个常量**）✓

## 四、读写规则（**照主人的语义**）

### 输入（**每帧拼进观测**）
```
A 跑时读： A 的记忆（自己上帧写的） + B 的记忆（B 上帧写的）
B 跑时读： A 的记忆（A 本帧刚写的） + B 的记忆（自己上帧写的）
```
⟹ **`2` 份 × `2` token × `256` 维 = `1,024` 维**（**相对 `10,540` 维的观测是 `9.7%`**）✓

### 输出（**每帧写回**）
```
A 只写 A 区；B 只写 B 区（对方那份【原样不动】）
```
**写 = 网络回归头输出的 `K × 256` 个数**，**经 `tanh` 钳到 `[-1, 1]`** ✓

### 时序（**主人已定**）
```
第 N 帧：  A 先跑（读 B 上帧、写 A 区）→ B 后跑（读 A 本帧、写 B 区）
```
⟹ ⭐ **跨帧通信、无竞争条件** ✓

### 初始化
**全零** ✓

---

## 五、为什么用 `tanh`（**而不是别的**）

| 方案 | 评价 |
|---|---|
| ⭐ **连续值 + `tanh` → `[-1,1]`** | ✅ **改动最小、无需额外投影**；⚠️ **回归头在 RL 里学习曲线可能慢** |
| **离散化（每维 `n` 档）** | ✅ **可当分类训（RL 更顺手）**；⚠️ **输出头 × `n` 倍、且失去连续性** |
| **直接让网络输出"原始浮点"** | ⛔ **无界 ⟹ 数值不稳定、且观测侧归一化对不上** ✗ |

**⟹ 定：`tanh` → `[-1,1]`**（**观测侧也按 `[-1,1]` 给** ⟹ **读写同一量纲**）✓
⚠️ **如果将来发现"回归头训不动" ⟹ 再换离散化**（**那是一个可局部替换的决定**）✓

## 六、采集器要不要记记忆？—— ⭐ **不要，但【要留维度】**

**推理**：
- **记忆是【网络自己产生的】** ⟹ ⚠️ **采集时【还没有网络】** ⚠️
- ⟹ ⭐ **采集时该段 = 【全零】**（**或将来"用规则版 AI 的伪记忆"，但先不做**）✓
- ⭐ **而"训练时"记忆由网络自己写、自己读** ⟹ **采集器不需要记它** ✓✓

**⟹ 采集器只需**：**把这段的维度【预留出来、填零】**，**别让它变成"以后加维要改布局"** ✓
（⚠️ **这正是"留空不占维度（防假账）"那条裁定的边界** ——
**"防假账"的意思是"没有的东西不许占位假装有"，而"预留维度"是"架构上先划好位置"**。
本设计**倾向"预留"**，因为**记忆是【已定案要有的】、不是"可能有"** ✓）
