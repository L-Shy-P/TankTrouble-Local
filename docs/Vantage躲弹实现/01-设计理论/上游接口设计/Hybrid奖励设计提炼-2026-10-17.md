## 一、它是 `9` 个**独立通道**（不是"一个奖励函数"）

`reward.rs` 的 `REWARD_CHANNELS = 9`，名字与含义（`CHANNEL_NAMES` / `CH_*` 常量）：

| # | 通道 | 干什么 | 关键机制 |
|---|---|---|---|
| `0` | ⭐⭐ **`initiative`（主动权）** | **"我比对手更接近'好射位'"** | ⭐ **势函数塑形**（**见下 §二**）|
| `1` | **`paint_toggle`（风格）** | **前进加分 · 后退扣分 · 来回摆动扣分** | **鼓励推进、惩罚犹豫**；**带"每步/每回合上限"** |
| `2` | **`terminal`** | **`win +1 / loss −1 / 双死 −0.25 / 超时 0`** | 终局 |
| `3` | ⭐⭐ **`kill_quality`** | **`sqrt(飞行时间质量 × 剩余弹药质量)`** | ⭐ **`30%` 延迟发放 + 时间衰减信用分配**（**见下 §三**）|
| `4` | **`example`** | **前 `5` 发命中** | 起步引导（**"先学会打中"**）|
| `5` | ⭐ **`precision`** | **"路径 `≥8` 格 或 飞行 `≥5` 秒" + 【必须有反弹】** | ⭐ **引导特定技巧**（**这张图"直射机会很少"**）|
| `6` | **`knife`** | **贴身击杀**（车体多边形相交）| 引导近战 |
| `7` | ⭐⭐⭐ **`dodge`（躲避）** | **"假想命中帧"到了我还活着 ⟹ 给分** | ⭐⭐⭐ **反事实奖励**（**见下 §四 —— 最值得学的**）|
| `8` | **`repeated_wall`** | **"连续 `≥3` 帧有输入却没位移" ⟹ 扣 `−0.01`** | **治"卡住不动"** |

## 二、⭐⭐ `initiative` 是标准的**势函数塑形**（`potential-based shaping`）

`reward.rs::update_initiative_and_style` 逐字：
```rust
self.phi = [self.potential(g, 0), self.potential(g, 1)];
self.z = self.phi[self.me] - self.phi[1 - self.me];
if let Some(previous) = self.prev_z {
    self.add(CH_INITIATIVE, self.config.initiative_lambda * (self.config.gamma * self.z - previous));
}
```
**⭐ 那就是 `Ng, Harada, Russell (1999)` 的经典形式 `r' = r + λ(γΦ(s') − Φ(s))`** ✓
**⭐⭐ 它保证"不改变最优策略"** —— **所以可以放心加、不会把 AI 带偏。**

**⭐ 而"势函数 `Φ` 是什么"**（`potential_from` 逐字）：
```rust
let guidance = Self::bilinear(field, x, y, false);     // 引导场
let density  = Self::bilinear(field, x, y, true);      // 密度场
let alignment = ... best_aim_at(...) ...;              // 枪口对准最佳射角
((phi_guidance * guidance + phi_density * density + phi_alignment * alignment) / sum)
```
**默认权重**：**`guidance 0.60 · density 0.30 · alignment 0.10`** ✓
**而 `field` 来自 `InverseDensityFieldBuilder`（反向射线 → 射击位密度场）** ✓

> ⭐ **所以"涂色"这个词的真实含义**：**它不是"在格子上涂颜色"的奖励**，
> 而是**"把'哪些格子是好的射位'做成一张势能场，然后用势函数塑形把 AI 引过去"** ✓✓

## 三、⭐⭐ `kill_quality` 的**两段式信用分配**（`0.70` 立即 + `0.30` 追溯）

`reward.rs::process_hits` 逐字：
```rust
let quality = self.config.kill_quality_cap * (q_time * q_ammo).sqrt();
self.add(CH_QUALITY, 0.70 * quality);                       // 命中帧立即给 70%
self.pending.push(PendingPayout { channel: CH_QUALITY, total: 0.30 * quality, index: 0 });
```
而 `30%` 在"命中前 `12` 秒的准备历史"里按**时间衰减**分配（`preparation_weights` 逐字）：
```rust
let increment = (phi - base).max(0.0).sqrt() - (high - base).max(0.0).sqrt();
let age_seconds = (hit_frame - frame).max(0) as f64 / C::FPS as f64;
let weight = increment * (-age_seconds / 3.0).exp();        // ⭐ 越接近命中、权重越大
... 归一化到和为 1 ...
```
**⭐⭐ 那等于"手工实现了一次'功劳往前分'"** —— **而它分配的对象是"那几步'准备动作'"** ✓✓

## 四、⭐⭐⭐ `dodge` 是**反事实奖励**（**这一段最值得学**）

`reward.rs::update_dodge` + `simulate_laika_hit` 逐字：
```rust
fn simulate_laika_hit(g, me, eligible) -> Option<i64> {
    let mut branch = g.clone();                              // ⭐ 克隆整个世界
    branch.ai_enabled[me] = true;
    branch.ais[me] = Some(LaikaAI::new(branch.scale, me));   // ⭐ 让"脚本 AI"替我开
    for step in 1..=DODGE_FRAMES {                           // 75 帧 = 3 秒
        branch.step();
        if ...我被打死... { return Some(step); }
    }
    None
}
```
**逻辑**（`update_dodge`）：
1. **有敌弹威胁时**（`detects_enemy_bullet_danger`）⟹ **克隆世界、让"脚本 AI"代打 `75` 帧**
2. **若"那个脚本 AI 会死"** ⟹ **记下"假想命中帧"**（**⟹ 这里被定义为"危险"**）
3. **而"真实的我"活过了那个帧** ⟹ ⭐ **给躲避奖励（`70%`）**
4. **再过 `75` 帧确认还活着** ⟹ ⭐ **再给 `30%`**
5. **同一发子弹只算一次**（`dodge_seen`）；**每回合有上限**（`dodge_round_cap`）

**⭐⭐⭐ 为什么这是好东西**：
- **"危险"不需要人标注、也不依赖价值函数** —— **由"一个已知很笨的对手会死"来定义** ✓✓
- **"活下来了"就是"躲成功了"** ⟹ **奖励【稠密】且【反事实】** ✓✓
- **它把"稀疏的'活到最后'"拆成了"每颗子弹一次机会"** ⟹ **样本效率大幅上升** ✓✓

## 五、⭐ 我们能直接借的（**按优先级**）

| 优先级 | 借什么 | 怎么落到我们这 |
|---|---|---|
| ⭐⭐⭐ | **"反事实躲避奖励"** | **用"某个固定基线策略"在沙盒里代打 N 帧；若它会被打死、而我没有 ⟹ 给躲避分** —— **我们已有 `__vtTileDist` 和树，能造"假想分支"** |
| ⭐⭐⭐ | **势函数塑形（`initiative`）** | **用"我们自己的危险/机会场"当 `Φ`，加 `λ(γΦ' − Φ)`；**有"不改变最优策略"的定理兜底** |
| ⭐⭐ | **多通道 + 每通道上限** | **`9` 个通道各自封顶** ⟹ **防"刷单一奖励"**（**它每个通道都有 cap**）|
| ⭐⭐ | **追溯信用分配** | **"击杀/存活"的功劳往前按 `exp(−age/3s)` 分给准备动作** |
| ⭐ | **"撞墙/无位移"小惩罚** | **治"卡住不动"**（**我们的树 AI 也踩过这类）** |
| ⭐ | **`precision`（只奖反弹击杀）** | **"引导特定技巧"** —— **我们要引导的是"躲"、可以类比成"只奖'险中求生'的躲"** |

## 六、⚠️ 注意事项（**照抄会踩的坑**）
1. **它的 `dodge` 依赖 `LaikaAI` 可克隆、可前推** ⟹ ⭐ **我们这边"代打者"是谁要选好**（**树 AI 太贵、可能要用便宜基线**）；
2. **它的 `initiative` 依赖"密度场"，那场每帧重算** ⟹ **我们若不建场、势函数就要另找**；
3. **`dodge` 的 `70%+30%` 与 `kill_quality` 的 `0.70+0.30` 都是"手工打折"** ⟹ **不是定理、是经验参数**（**它自己也是 `RewardConfig` 里可调的**）✓
