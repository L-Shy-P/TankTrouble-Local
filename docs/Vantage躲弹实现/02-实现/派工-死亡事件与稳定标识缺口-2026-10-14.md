> **性质**：核查结论 + 派工。设计定案全部有出处；本文只指出"实现与定案的差"。

## 二、核查发现（按严重度）

### 🔴 E1 真 bug：死亡事件的"谁死"**恒为 −1**

`vantage_observe.js:383`：

```js
g.push(last ? num(last.victimPlayerId, -1) : -1, …)
```

而 `num()`（`:83`）= `(typeof x === 'number' && isFinite(x)) ? x : 默认值`；
`victimPlayerId` 是**玩家 id 字符串**（`'tank_a'`，`vantage_sandbox.js:3485` `victimPlayerId: pid`）。
⟹ **`num("tank_a", -1)` 永远返回 −1** ⟹ token 里"谁死"这一维**恒为垃圾值**。

**同族先例**：`proj[].rot` 恒 NaN（AGENTS.md 假阳率纪律）。**这次连 NaN 都不是，是静默的 −1。**

### 🔴 E2 缺字段：§9.2#6 要 5 项，token 只有 3.5 项

现状（`:380-386`，4 维）：`dVictim`（坏的，见 E1）+ `dX` + `dY` + `dT(tWallMs)`。

| §9.2#6 要的 | 现状 | 数据在吗 |
|---|---|---|
| 谁死 | ❌ 恒 −1（E1） | ✅ 记录里有（字符串，需映射） |
| 位置 | ✅ dX/dY | ✅ |
| **角度** | ❌ **缺** | ✅ **记录里有** `rec.rot`（`sandbox:3496`，销毁前取的） |
| **被谁打死** | ❌ **缺** | ✅ **记录里有** `killerPlayerId`（`sandbox:3486` 初始化+回填） |
| **用什么武器** | ❌ **缺** | ✅ **记录里有** `deadlyType`（同出处） |
| 时间戳 | 🟡 有但是墙钟毫秒（见 E3） | — |

**缺 killer 的直接后果**：主人定的"**自爆不用标，因为会标击杀来源**"机制**失效**——没有 killer 就分不清自杀和他杀，这句定案的前提被实现破坏了。

### 🟡 E3 时间基准混用：`dT` 用墙钟毫秒

观测里其他时间量全是**帧/秒**（`tRel` 秒、`rootLag` 秒、`lifeLeft` 秒），唯独 `dT` 是 `tWallMs`（墙钟毫秒，`sandbox:3493`）。虚拟时钟下能跑，但这正是"**时间基准多层**"老坑的形态（本项目已为"同一概念两套口径"付过多次代价）。
**建议**：改**帧基年龄**（`当前帧号 − 死亡帧号`，死亡记录里补一个 `frame` 字段）或树时钟秒；二选一，写进字段表。

### 🟡 E4 单槽：只编码"最近一次"死亡（`deaths[length-1]`）

1v1 经典模式可接受（死亡即终局）；DM/多人会丢历史。建议 `K_death` 作参数（同 `K_fire` 待遇，**不许把 1 写死在布局里**），当前取 1。

### 🟡 E6 关联项：**稳定标识整体缺失**（§9.2#12）

- 对手段（`encodeGlobal` 的 opp 循环）**也没有 id**，靠**数组顺序**认人——`keyList(tanks)` 的对象键顺序在有人死亡/复活时可能变；
- E1/E2 的 victim/killer 也需要同一套映射。
- ⟹ **这是一件事**：建一张**玩家稳定整数索引表**（自车 = 0；对手按稳定键排序 = 1..N，跨帧不变），死亡事件、对手段、上帧计划全部用它。

## 三、派工清单（施工侧）

| # | 动作 | 验收 |
|---|---|---|
| P1 | **修 E1**：victim/killer 走稳定整数索引（见 P4），⛔ 不许再把字符串 id 喂 `num()` | 打印一局：死者的 victim ≠ −1 且与 `getDeaths()` 记录对得上 |
| P2 | **补 E2**：死亡事件 4 → **7 维** = `victimIdx, x, y, rot, killerIdx, deadlyType, tAge`（rot/deadlyType/killer 全部已在死亡记录里，纯编码工作） | 逐字段打印；`killerIdx == 0`（自车索引）= 自杀，可判别 |
| P3 | **定 E3**：`dT` 改帧基年龄或树时钟秒（**先在字段表里定，再改代码**） | 与 `tRel`/`rootLag` 同一时间基准（对拍：同一致局下三者单位一致） |
| P4 | **建稳定玩家索引表**：自车=0、对手稳定排序=1..N；**顺序跨帧不变**要有证明（探针：连续 60 帧索引不变；有人死亡/复活后也不变） | §9.2#12 落地 |
| P5 | **E4**：`K_death` 参数化（当前=1） | 编码器按参数写，不写死 |

> ⚠️ P1/P2 是**观测语义修复**（定案 vs 实现的差），不是新设计；P3 要先定口径再动手（防又造一套时间基准）。
