## 二、6 种武器的炮塔 / 出膛常量表（**带出处**）

### 2.1 炮塔 fixture **到底怎么建**（先回答"是不是 `weapon.getTurretShape()`"）

**不是。全仓没有 `weapon.getTurretShape()` / `turretShape` 这种 API（`grep` 命中 0 条）。**
炮塔 fixture **只有一个建法**：

```js
// game_core/js/b714588dc4621fe104113111ba90b1a7.js（Constants + B2DUtils）
B2DUtils.updateTankBodyTurret: function(b2body, tank, weapon) {
  // ① 先删掉所有 userData.type === "turret" 的夹具  ② switch (weapon.getType())
  //    → _createBulletTurretFixtureDefs / _createLaserTurretFixtureDefs / … 
  //    → 每个 _create* 里几何【全部】读 Constants.<X>_TURRET.*（px/20 = m）
}
```
`【读码】`（美化副本 `_tools/headless/_i4_tmp/_i4_game_constants.js`）：`updateTankBodyTurret` 在 **L1429**，
6 个工厂函数在 **L1476 / L1492 / L1521 / L1541 / L1553 / L1569**。

**形状改变的 3 个触发点**（= `updateTankBodyTurret` 的全部调用点）`【读码】`：
① `RoundModel.setWeaponState`（拾取 / 装填）② `RoundModel.updateWeapon`（**导弹发射后**）③ `RoundModel.destroyWeapon`（武器用尽 → 换下一个）。
沙箱**不复制**这 3 个触发点，只**每帧读"当前武器是谁"** ⟹ 天然跟着上面 3 条走。
