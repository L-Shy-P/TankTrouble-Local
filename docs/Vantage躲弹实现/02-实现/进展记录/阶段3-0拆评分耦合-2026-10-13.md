## 三、拆法（每处改成什么机械判据 + 依据出处）

### 3.1 新机械判据：`dead` + `deathFrame`（`samples` 可选）

```js
// vantage_tree.js（本步新增，物理应用；节选）
function applyRolloutPhysics(tree, node, r) {
    if (!node || !r || r.dead === undefined || r.deathFrame === undefined) return false;
    var planned = plannedFramesOf(node);
    var actual  = rolloutActualFrames(tree, node, r);      // = safeFramesForDeath 口径
    if (actual < planned) recordStructure(tree, 'death-shorten', …);
    node.segmentFrames = actual;
    if (node.rolloutSamples && node.rolloutSamples[actual]) node.simState.tank = {…};
    if (typeof node.rolloutStartT === 'number') node.simState.tGlobal = node.rolloutStartT + actual * FRAME_DT;
    node.tEndSec = tree.rootAbsT + node.simState.tGlobal;
    if (actual < planned && node.children.length) invalidateDescendants(tree, node);
    node.status = (r.dead && r.deathFrame >= 0 && r.deathFrame <= planned) ? 'dead' : 'alive';
    node.fullDead = !!r.dead;
    node.fullDeathFrame = r.dead ? r.deathFrame : -1;
    return true;
}
```

* **依据（方针 `3-0`）**：「把函数拆成「物理应用」（**守卫 `samples/dead/deathFrame`**，
  智能体版用）与「评分应用」（`segmentScore/subtreeBest`，规则版专用）」
  —— 见《智能体版-总体路线方针-2026-10-10》阶段 3 表 `3-0` 行。
* **依据（权威版 §21.5 ⑤施工含义）**：「不能"只删调用" —— 必须先造一条**不返回分数的
  模拟/判死通道**（`samples` + `deathFrame`），再处理 `probeSegment` 的段长来源，
  最后才删分项与选路器」⟹ 本步只做**第一步**。
* **依据（权威版 §4）**：「**规则层过滤，不是奖励项/惩罚项/"选不选"**」
  「合法帧 = 死亡帧之前的帧。规则层直接把 `f ≥ deathFrame` 的候选划掉」
  ⟹ 死亡 = **机械过滤**，`fd` 是事实、不是分数 ⟹ 不许被"没有分数"挡住。
* **`fd` 纪律**：`safeFramesForDeath` 对 `fd ≤ 1` 折成"执行 1 帧"（**执行帧数**），
  `fullDeathFrame` 原样保留 `0`（`fd=0` 合法）；本步**没有**把任何 fd 改写成 1。
* **`fullDeathFrame` 保留**：权威版 §4 明说它是**有意的观测字段**（"给它事实，不给它结论"），
  本步**没有**删它（§16.4 说的"观测里删"是编码器那件事，不是树）。

### 3.2 分支策略：`agentPathActive` + `applyRolloutResult`

```js
function agentPathActive(tree) {
    if (!tree || !tree._agentDecision) return false;              // ★ 关键：本帧没决策 → false
    if (typeof VantageTreeInterface === 'undefined' || !VantageTreeInterface.Agents) return false;
    var a = VantageTreeInterface.Agents.current();
    return !!(a && a.name !== 'rule');
}
function applyRolloutResult(tree, node, r) {
    if (agentPathActive(tree)) {
        var physOk = applyRolloutPhysics(tree, node, r);
        applyRolloutScore(tree, node, r);      // 有评分才写；没有 → 安全返回 false
        return physOk;
    }
    return applyRolloutScore(tree, node, r);   // ★ 规则版：原函数、原行为
}
```

* **依据（权威版 §5）**：「以上都是**智能体版 Vantage 的新语义，并不影响规则版**」；
  「新语义**只在 `Agents.current()` 不是规则智能体时生效**」；
  「实现时**不许**为了新语义去改规则版的路径」。
  ⟹ 所以是**分支**，不是"直接改掉"；`applyRolloutScore` 本体保持原样（§五-0 逐字节证明）。
* **`_agentDecision` 也进判据的理由**：验收要求「`Agents.use('nn')` 但 `decide` 返回
  `null` 时与规则版**逐帧一致**」⟹ 没决策（未就绪/重试超限/接口未加载）必须走原路径。
  ⚠️ 这是**本步的分支键选择**；若后续 3-1/3-4 认为"智能体模式下即使本帧没决策也该走
  新通道"，那是**下一步的语义**，本步不擅自改。
