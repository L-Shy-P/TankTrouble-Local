### N3 这次 PASS 为什么是真的（不是“弹没动”）

矩阵 `_probe_laser_wall_matrix.js`（6/6 PASS）：

```text
N3 + 墙   + 正确速度  dead=true  fd=0
N3 + 无墙 + 正确速度  dead=false
N2 + 墙   + 正确速度  dead=false
N2 + 无墙 + 正确速度  dead=true  fd=0
N2 + 墙   + 错误单位  dead=false
N3 + 墙   + 错误单位  dead=false
```

推理：**N2 无墙=true** ⇒ 弹确实从 `(1.5,0.5)` 飞了整步到 `(4.05,-2.05)`（不是没动）；**N2 有墙=false 且 N3 有墙=true** ⇒ 墙先把直射挡住、再按镜面把弹送到 `(4,2)`；**N3 无墙=false** ⇒ N3 的命中确实来自墙而不是直射。错误单位两格=false，正是旧探针的原形。

## 八 这次 N3 的教训（给 `AGENTS.md` 的素材）

### 1. 探针单位错了会怎样

- `_probe_laser_wall_cases.js` 的 oracle 用“一帧位移 `p0→p1`（2.5456m）”，但调 `rolloutBatch` 时把同一个数传给了 `vx/vy`；Rust 的 `vx/vy` 是**速度**（`rollout.rs:996` 直接 `set_body_linear_velocity`，Step 按 `v*dt` 积分）。于是 Rust 里的弹每帧只走 `2.5456*0.02=0.0509m`，**比 oracle 少 50×**。
- 结果：N3 `dead=false`；N2 也 `false`。我把 N2 的 false 误读成“墙挡住了”，把 N3 的 false 误读成“CCD 截停导致反射段消失”，据此写了一版**“并行意图段”补丁**（JS+Rust）——**追了一个不存在的产品 bug**，白做一轮补丁；最后发现补丁后再怎么调 N3 还是不 PASS（因为弹没动，和补丁无关），才回头查探针输入单位。
- 教训：**探针的输入单位错了，会把“测试自己的 bug”伪装成“产品的 bug”，而且会引导出方向完全正确的“修法”去修一个不存在的问题。**

### 2. 为什么“双错抵消”很危险

- 这次不是两个错互相抵消，而是**一个错把两个用例都变成假绿/假红**：
  - N2 的 `PASS` 是假绿——弹几乎没动，当然不命中；它**根本没在测“墙挡住”**。
  - N3 的 `FAIL` 是假红——不是产品漏反射，是弹没走到墙。
- 假绿比 FAIL 更危险：矩阵看起来“N2 过了”，会让人以为墙逻辑已验证；如果只有一个探针、没有几何 oracle 和无墙对照，这个假绿会一路带进收口。**测试因为错误的原因 PASS，等于没有测试。**

### 3. 怎么防

1. **先验输入单位，再怀疑产品**：知道 bridge API 的单位合同（`rolloutBatch.bullets[].vx/vy` = m/s），探针构造输入时显式写 `(p1-p0)/dt` 并断言 `|v|`、`|Δp|/dt` 自洽；oracle 用的段长必须与模拟实际步长一致（或在注释里显式说明 dt 差异）。
2. **判据不能只看 `dead`**：要能区分“没动/穿过/反射”三种解释。这次用**无墙对照**（N2 无墙应 true、N3 无墙应 false）把“没动”和“穿墙”都钉死；能拿 mid-flight body 位置或 sweep 命中记录更好。
3. **红绿都要有对照**：墙挡住（N2）必须有“无墙会命中”的对照，才算真的测了“墙”；反射命中（N3）必须有“无墙不命中”的对照，才算真的测了“反射”。
4. **“产品看起来该有 bug、但怎么改都不对”时，先怀疑探针/夹具输入**：我这次就是补丁越写越绕、现象用假设解释不通（`pos_k` 编码出来的位置是对的、哨兵又“不返回”），这些矛盾本身就是“测试输入错了”的信号。
5. **纪律要区分性质**：不许改探针是为了防“用改测试掩盖产品缺陷”；当能证明“产品是对的、测试自己错了”时，停下报告、等批准再改测试，而不是硬改产品。这次按纪律停下，省下了一个不该合的补丁。
6. **另一个探针也要审计**：`_probe_laser_sweep_counterexample.js` 的 `v=180`（m/s）与沙箱 `FRAME` 自洽，5/5 是真命中；但它用的是沙箱 `0.02s`（3.6m/帧）而 oracle 用真游戏 `3.06m/帧`——这是已知的 16/17ms 相位问题（1-1/1-3），要在报告里写明，不要当成单位 bug 或偷偷“修 oracle”。
