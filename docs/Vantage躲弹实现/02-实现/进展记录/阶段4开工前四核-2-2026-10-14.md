## 三、⭐⭐ ② `Math.random` 覆盖的**实测**（探针 `_tools/headless/_rng_cov.js`，真 Chrome）

**方法**：真局里打开 `__vtRng.recordFlat()` → 记录 `dump()` 长度 → 调用 `Math.random()` ×3 + `MathUtils.randomArrayEntry([11,22,33])` → 再量长度；随后 `play(seq)` 重放，再取 `Math.random()` ×3 比对。

**原始输出**：
```
A_RECORD {"keys":["debugFirst","debugStacks","trace","dumpTrace","traceLen","record","recordFlat",
                 "stop","play","playSites","dump","dumpSites","useCounts","stacks","state"],
          "mode":"recordFlat","before":0,
          "vals":[0.8499899940703431,0.6873022689244411,0.47321946132396],
          "arr":22,"after":4,"delta":4,
          "dumpTail":"[0.8499899940703431,0.6873022689244411,0.47321946132396,0.34158221166904146]","seqLen":4}
B_REPLAY {"seqTop":4,"played":"play",
          "replay":[0.8499899940703431,0.6873022689244411,0.47321946132396]}
```
**结论（逐条）**：
1. ⭐ **`Math.random` 被覆盖**：`delta = 4`（3 次 `Math.random` + 1 次 `randomArrayEntry`），且 **`dumpTail` 里就是刚才那 3 个值**（`0.8499…/0.6873…/0.4732…`）⟹ 不是"条目数变了"的错觉，**值本身被记下** ✓
2. ⭐ **`MathUtils.randomArrayEntry` 也被覆盖**（第 4 个值 `0.3415…`；返回 `22` 与 `[11,22,33]` 一致）⟹ **箱子生成用的 `getRandomUnusedPosition`/`crateTypes[floor(rand*len)]` 这类路径在覆盖范围内** ✓
3. ⭐ **往返一致**：`play(seq)` 后 `Math.random()` ×3 **逐值等于**记录值（浮点位级相同）✓
4. **覆盖清单（本轮实测）**：`Math.random` ✓ · `MathUtils.randomArrayEntry` ✓（**其余随机源未列**：如 `crypto.getRandomValues`/`Date.now` 类，本轮未测 —— 但游戏侧随机基本都走这两条）
