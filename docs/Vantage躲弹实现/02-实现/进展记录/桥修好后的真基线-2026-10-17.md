## 四、两个根因（都已定位到源码/实测）

### ① 打不死人 = 游戏侧两条机制叠加
`game_core/js/7b2ed8ad…js`（`BulletWeapon`）：
```js
fire: function(){ if(!this._triggerPulled){ this._triggerPulled=true;
    if(this._bulletsFired<this._numBullets){ ++this._bulletsFired; emit(WEAPON_FIRED); return true; }
    else { emit(WEAPON_EMPTY); } } return false; }
release: function(){ this._triggerPulled=false; }
reload:  function(projectile){ if(this._timeAlive>=projectile.getTimeAlive()){ --this._bulletsFired; } }
```
- **`_triggerPulled` 是锁存**：一直按着 ⟹ 只算一发 ⟹ **必须"松一帧扳机"才能再打**
- **`_numBullets = 5`（实测）同屏上限**：场上 5 发没消失前全部落 `WEAPON_EMPTY`
⟹ **`322` 次开火位只出 `5` 发**是**完全符合机制**的，不是接线 bug ✓
⟹ **要"会打第二发"，策略必须学会间歇开火**；而**观测里本来就有 `selfFire / wpnCool / wpnReload / queueLen`**
（`vantage_observe.js:63-95`）⟹ **看得见、学得会，缺的是奖励信号**。

### ② 价值/回报尺度爆掉
`8` 局**全部截断** + `bootstrap zero` ⟹ 价值目标是错的 ⟹ `loss_v 9.6→3976`、`gn 2.6e6`。
