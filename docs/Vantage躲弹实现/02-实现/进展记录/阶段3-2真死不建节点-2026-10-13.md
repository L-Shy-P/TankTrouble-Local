### 2.1 真死不建：`buildCandidate` 的智能体分支（`vantage_tree.js:4400-4440`）

```js
if (agentPathActive(tree)) {
    var L = agentValidFramesOf(r);            // §7.7：没死 75；非真死 fd−1
    if (L <= 0) return null;                  // ★ fd≤1（L≤0）= 真死 → 不建节点
    var sA = r.samples && r.samples[L];       // 节点状态 = samples[L]（建在死前）
    var childA = createTreeNode(parent, ops[opIdx].inputs, {
        tank: { x: sA.x, y: sA.y, rot: sA.rot },
        tGlobal: parent.simState.tGlobal + L * FRAME_DT });
    childA.validFrames = L;                   // ★ 独立新字段（不从 segmentFrames 借）
    childA.backMax = L - 1;                   // B 的 back 上限
    // ⛔ 不写 segmentFrames / plannedFrames / rolloutFrames
    childA.segmentScore = (probe && probe.cum && probe.cum[opIdx])
        ? probe.cum[opIdx][Math.min(L, probe.cum[opIdx].length - 1)]
        : (typeof r.totalScore === 'number' ? r.totalScore : 0);   // ← NaN 修的可走到分支
    ...
}
// ── 规则版：以下**逐字节原样**（§5） ──
var segF = probe.segmentFrames; ...
```

* **边界**：`fd=0`（起手就撞）与 `fd=1`（走一步就死）都 → `L = -1 / 0` → **不建**（方针 3-2 的坑，
  `fd−1` 算出的 0/−1 不落到"夹 1 帧"的旧写法上）。
* **"缺席即标记"**：`attachResults`（`:4905-4930`）里 `buildCandidate` 返回 `null` 就

  （它确实"生长过"，只是没有可建的分支）。
