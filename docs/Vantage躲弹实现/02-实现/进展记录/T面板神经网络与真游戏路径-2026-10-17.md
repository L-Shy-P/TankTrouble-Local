## 十、防抖动修复（主人 `2026-10-17` 实测：「面板快速上下抖动，几乎不可读」）

**根因**：逐帧视图内容长度每帧都变（`opName` 长短 / `inputs` 项数 / `rejected` 条数），
每次重排 ⟹ 容器行高变化 ⟹ 整块上下跳。

**修法（逐条对照主人给的方案）**：

| 等宽 + 固定列宽 | `font-family:Consolas,monospace` + `padCjk()`（**中文按 2 列**算宽度，⛔ 不用 text-align） |
| 数字统一位数 | `lp/v` 4 位、`routeLen/moved` 2 位 |
| 刷新节流 ≥250ms | `renderFrameView()` / `renderRolling()` 内 250ms 闸门；**导出仍按帧全量**（`S.hist` 每帧都 push） |
| 只更新文本节点 | 只写 `textContent`；`renderCompat()` 也加了"内容没变就不碰 DOM"缓存 |
| 滚动表新的在顶部 | `slice(-60).reverse()` + `scrollTop=0`，整块 `textContent` 覆写 |
| 不挤压老实验区 | 面板 `overflow-y:auto` + `#vt-exp-rows` `min-height:140px`（⛔ 老内容一条没删） |
