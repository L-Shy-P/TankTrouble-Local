## 十、防抖动修复（主人 `2026-10-17` 实测：「面板快速上下抖动，几乎不可读」）

**根因**：逐帧视图内容长度每帧都变（`opName` 长短 / `inputs` 项数 / `rejected` 条数），
每次重排 ⟹ 容器行高变化 ⟹ 整块上下跳。

**修法（逐条对照主人给的方案）**：
| 要求 | 落地 |
|---|---|
| 容器定高 + 内部滚动 | `#vt-agent-frame` `height:52px;overflow-y:auto`；`#vt-agent-roll` `height:96px;overflow-y:auto`；整个 `#vt-agent-rows` `max-height:360px;overflow-y:auto` |
| 每行固定行高 | `line-height:16px; white-space:nowrap`（frame）/ `white-space:pre`（roll） |
| 等宽 + 固定列宽 | `font-family:Consolas,monospace` + `padCjk()`（**中文按 2 列**算宽度，⛔ 不用 text-align） |
| 数字统一位数 | `lp/v` 4 位、`routeLen/moved` 2 位 |
| 刷新节流 ≥250ms | `renderFrameView()` / `renderRolling()` 内 250ms 闸门；**导出仍按帧全量**（`S.hist` 每帧都 push） |
| 只更新文本节点 | 只写 `textContent`；`renderCompat()` 也加了"内容没变就不碰 DOM"缓存 |
| 滚动表新的在顶部 | `slice(-60).reverse()` + `scrollTop=0`，整块 `textContent` 覆写 |
| 不挤压老实验区 | 面板 `overflow-y:auto` + `#vt-exp-rows` `min-height:140px`（⛔ 老内容一条没删） |

**验收（`D:/vt_run/evidence/panel_jitter.json`，真游戏 60 次采样/98 帧）**：
- `#vt-bench-panel` 外框：**只有 1 种矩形** `{top:8, h:773.6, w:361.6}` ⟹ **位置与高度逐帧不变**
- `#vt-agent-rows`：1 种 `{top:167.3, h:368.8}`；`#vt-agent-frame` 1 种 `{top:452.3,h:54.8}`；`#vt-agent-roll` 1 种 `{top:510.1,h:98.8}`；导出按钮 1 种 `{top:611.9,h:21.2}`
- **刷新频率**：60 次采样里 frame 文本只变 **7 次**（≈250ms/次），而 `hist` 增长 **98 = tick 增长 98** ⟹ 视图节流、**导出不节流**
- **行宽恒定**：frame 两行显示宽度恒为 `200,200`（`padCjk` 生效）
- 老实验区 `#vt-exp-rows` 仍有 **148.8px**（可滚动），`exportVisibleAll=true`
- 样例一行：`f=517   N=286  row=247  uid=528   depth=10 op=静止    lp=-1.7284  v=15.8193   routeLen=10.00 fire 1/0/-   inputs ---- pickNode.inputs   moved=0.15`
