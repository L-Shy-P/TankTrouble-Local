**三条硬纪律（写进代码注释了）**：
1. **绝不碰 `VantageTree.noteDeath`**（会 `_frozen=true` 把树定死）；
2. **只走被批准的只读口** `VantageTree.collectAgentNodes` + `VantageTree.dumpDiagnostics`；
3. **`θ` 全仓唯一真源 = `VantageObserve.bulletTheta()`**（= `atan2(speedX, −speedY)`），调试页/探针/自证**都调它**，⛔ 不许各写一遍。

### 3.2 `θ` 为什么选 `atan2(speedX, −speedY)`

游戏朝向 = `SetLinearVelocity(sin(rot)*s, −cos(rot)*s)` ⟹ 前向 `(sinθ, −cosθ)` ⟹ `atan2(sinθ·s, cosθ·s) = θ` ✅
**代码内佐证**：`vantage_tree.js` 的 `moveTargetScore` 里写着
`var desiredRot = Math.atan2(dx, -dy);   // 游戏朝向：sin(rot), -cos(rot)` —— **同一个约定**。
**选它的理由**：观测里**自己坦克 `rot` 与对手角度都是这套** ⟹ 不制造第二套角；"角弹"要拿弹的航向和坦克朝向比 ⟹ 同套可直接相减。

### 3.3 ⚠️ `rootLag` 的一个实现陷阱（**已修，记档**）

`VantageTree.getTree()` 返回的是**视图对象**，**不带 `dumpDiagnostics`** ⟹ 第一版写成 `tree.dumpDiagnostics()` ⟹ **105 帧全 `available:false`**（幸好自证探针把它抓出来了）。
**修法**：改走**模块级** `VantageTree.dumpDiagnostics()`（它内部读 `_tree`），`tree.dumpDiagnostics` 只作兜底。

### 🔴 4.5 **但"没分支 + 生长过"这个样例，本轮【没能取到】—— 这是一条真发现，不是漏做**

**实测**：150~223 个采样帧、**82 次真子弹注入**、**`nTrueDeadRows = 1980`**（1980 个"`fd ≤ 1` 的真死节点"被观测到）⟹ **`hasGrown=1 且 children=0` 的节点：`0` 次**。

**连"真死候选"（`fd ≤ 1`）也会被建成节点**。而主人裁决的模型（"生过 + 没分支 ⟹ 真死"）隐含 **`§7.3` 的"真死不建节点"**，那是**阶段 3-2 的活**（`总体路线方针:118`）。
