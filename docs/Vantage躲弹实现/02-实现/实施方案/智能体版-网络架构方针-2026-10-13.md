## 一、候选编码选型记录（三选一）

B 的任务形式：给定候选集合（路线卡 × N + 子弹 token × M + 全局 token × 1），每张卡出一个 logit，masked softmax 选一。差别在**候选间要不要交互**：

| 选项 | 机制 | 候选间比较能力 | 参数量级 |
|---|---|---|---|
| **① Transformer encoder（✅ 选定）** | 全连接自注意力 | **完整**——可做集合级推理（"朝某方向的所有路线都危险"） | B ~2.3M |
| ② Deep Sets 式 | per-card MLP → mean+max 池化 → per-card 二次 MLP | 中——有全局上下文，无细粒度两两交互 | B ~0.5M |
| ③ 纯 per-card 打分 | `MLP(card_i, scene_summary)` → logit | 弱——argmax 仍有效，但分数函数形式上无法表达"i 的相对优劣取决于集合里还有什么" | B ~0.3M |

**选 ① 的理由（= 主人的选型依据）**：
1. softmax over candidates 要学"相对安全性"，候选间交互几乎是必须的；选项③的分数函数结构上缺少这一项；
2. 工程量最小——定案-10-06 的推理实测（N=496、d=256 L=3 ≈ 54ms/帧）就是按这个结构测的；
3. 性能已确认不是当前重点（主人 2026-10-10 裁决），不需要为省算力降级到 ②/③。
4. 选项 ②/③ 的真实代价不是算力，是**学习难度转移到卡片特征设计上**——卡片必须自足，否则网络没有信息可比较。

## 二、输入规格

### B 的输入

| 段 | 内容 |
|---|---|
| **路线卡 × N**（N = 叶子数，几百量级） | 终点位姿 `(dx, dy, dRot)`、路线总帧数、终点存活帧数、沿途最近子弹距离、沿途威胁帧计数、来路操作、深度、`backMax` ——【草案，终版随观测字段表关】 |
| **子弹 token × M**（M 可变，实测最多 67） | 位置(2)、速度(2)、类型(1)、剩余寿命(1)、`deadlyToOwner`(1)、`bounceTimestamps`(1) = **7 维**。⚠️ `bounceTimestamps` 是"最近 35ms 窗口内的撞墙时间戳数组"的摘要，**不是累计反弹次数**（"还剩几次反弹"在游戏里不存在） |
| **全局 token × 1** | 自车位姿/按键/武器/护盾、毒雾（作弊全开版：出现时间 + 安全区 4 边 + 下次方向）、上帧计划（路线 + 射击帧）、根滞后量、A/B 双份记忆槽 |

> **同源字段备注（主人 2026-10-13 指示）**：「终点存活帧数」「威胁帧数」「`backMax`」语义同源（都是"节点相对父节点的帧数"的衍生），**语义早已确认过，实现时厘清即可，不重新设计**。
>
> **红线复查**：上表所有卡片字段均为事实量；任何"安全度/危险度/评分"性质的派生量不许进卡。

### A 的输入

同构缩小：**可生长位置卡集合**（位置位姿、所属节点特征、`backMax`、帧号）+ 全局 token（与 B 同格式）。

## 三、结构与超参

```
token 序列 = [路线卡 × N | 子弹 token × M | 全局 token × 1]
  + 类型 embedding（卡 / 弹 / 全局 三类）
  + 不加顺序位置编码（集合无序；深度/帧号已在卡特征内）
  ↓
Transformer encoder（B: d=256 L=3 8 heads FFN4×；A: d=128 L=2）
  ↓
B: 路线头（N logits → masked softmax）
   射击头（选中路线的路径节点 {n_j}，每节点 backMax_j+1 个 sigmoid）
A: 位置头（masked softmax）+ back 头（以选中位置 token 为条件，[0, backMax] masked softmax）
```

**掩码规则（程序侧，结构保证合法）**：
- 路线头：只对合法叶子可设 logit，其余 `-inf`；
- back 头：只对 `[0, backMax]` 可设；
- 射击头：只计算选中路线上的节点，其余不算；
- ⟹ 阶段 0「学合法操作」的成本因此大降——**非法输出在结构上不可能**。

## 四、输出头细则

### B
1. **路线头**：N 个路线卡 token 各出一个 logit → masked softmax → 选一张卡 = 选定整条路（叶子选路定案，"选一个叶子 = 选好整条路线"）。
2. **射击头**：选中路线的路径节点序列 `{n_1..n_k}`（k ≤ 7），对每个节点输出长度 `backMax_j+1` 的 sigmoid 向量（逐段、逐 back 值的开火开关）。实现：以路线末 token 为条件过一个小 MLP，逐节点出 logits；成本 O(k×75)，可忽略。**不要求网络输出帧号/数数**（主人 10-10 否过"给路线的第几帧"方案）。

### A
- **位置头**：可生长位置卡 masked softmax → 选一个位置；
- **back 头**：以选中位置 token 为条件，输出 `[0, backMax]` 上的 masked softmax → 选回退帧数；
- 两个头**一次前向同时出**（back 头的输入是位置头的 softmax 加权或直接取选中 token，二选一由实现侧定，写进实现记录）。
